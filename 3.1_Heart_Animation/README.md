## Описание проекта

Программа постепенно рисует параметрическую кривую в форме сердца. Координаты вычисляются по математическим формулам, а Tkinter Canvas отображает точки и соединяет их линией. Скорость анимации можно менять во время работы.

## Функциональные возможности

- Пошаговое рисование кривой сердца.
- Регулировка скорости ползунком.
- Пауза и продолжение анимации.
- Повторный запуск с начала.
- Отрисовка с эффектом свечения без сторонних библиотек.

## Требования

- Python 3.10 или новее.
- Tkinter (обычно входит в установку Python).
- Сторонние библиотеки не нужны.

## Установка и запуск

Откройте терминал в папке проекта.

### Windows

```bash
python -m venv venv
venv\\Scripts\\activate
python main.py
```

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
python main.py
```

`requirements.txt` оставлен в репозитории для фиксации зависимостей; проект использует только стандартную библиотеку Python.

## Управление

- **Пауза / Продолжить** — остановить или продолжить анимацию.
- **Заново** или клавиша `R` — начать рисование сначала.
- Ползунок **Скорость** — изменить скорость построения.
- `Пробел` — пауза или продолжение.

## Математическая идея

Используется параметрическая кривая:

\[
x(t)=16\sin^3(t)
\]

\[
y(t)=13\cos(t)-5\cos(2t)-2\cos(3t)-\cos(4t)
\]

Параметр `t` постепенно увеличивается от нуля до \(2\pi\). Поэтому на экране появляется всё большая часть контура. В экранных координатах ось Y направлена вниз, поэтому значение Y при отрисовке инвертируется.
