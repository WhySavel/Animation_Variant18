## Описание проекта

Программа рекурсивно строит кривую Гильберта — фрактальную кривую, которая при увеличении порядка всё плотнее заполняет квадрат. Построение анимировано: сегменты появляются постепенно, а цвет линии плавно меняется по всей палитре.

## Функциональные возможности

- Рекурсивная генерация кривой Гильберта.
- Анимация постепенного появления линии.
- Плавное изменение цвета сегментов.
- Выбор порядка рекурсии от 1 до 6.
- Регулировка скорости.
- Пауза, продолжение и перезапуск.

## Требования

- Python 3.10 или новее.
- Tkinter и стандартная библиотека Python.
- Дополнительные библиотеки не требуются.

## Установка и запуск

### Windows

```bash
python -m venv venv
venv\\Scripts\\activate
python main.py
```

### macOS / Linux

```bash
python3 -m venv venv
source venv/bin/activate
python main.py
```

## Управление

- **Пауза / Продолжить** — приостановить или продолжить анимацию.
- **Заново** или клавиша `R` — перерисовать кривую с начала.
- **Порядок** — выбрать глубину рекурсии.
- **Скорость** — задать число сегментов, добавляемых за кадр.
- `Пробел` — пауза или продолжение.

## Как работает алгоритм

Кривая строится рекурсивно. На каждом уровне квадрат разбивается на четыре меньшие части, а порядок обхода меняется так, чтобы части соединялись в одну непрерывную линию. Для порядка `n` генератор возвращает \(4^n\) точек.

Цвет каждого отрезка зависит от его положения в последовательности. Для этого используется цветовая модель HSV, в которой оттенок постепенно меняется, а насыщенность и яркость остаются постоянными.
